# Plot Kernel

Plot Kernel

## Usage

``` r
plot_kernel_graph(
  M,
  xy = NULL,
  clrs = "black",
  scl = 1,
  labels = NULL,
  lab.cex = 0.6,
  arr.pos = 0.33,
  mn = 0.02
)
```

## Arguments

- M:

  a connectivity matrix

- xy:

  locations of the patches

- clrs:

  colors

- scl:

  scaling for graph thickness

- labels:

  a set of labels

- lab.cex:

  size of the labels

- arr.pos:

  position of the arrow

- mn:

  plot if weight is greater than mn

## Value

invisible
